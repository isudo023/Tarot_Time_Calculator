# 🔮 Tarot Timing Calculator

A Python-based Tarot Timing Calculator built using Streamlit.

## Features

- Single Card Timing
- Three Card Combined Timing
- Three Card Sequential Timing
- Upright and Reversed card orientations
- Custom starting date
- Visual tarot card images
- Sequential timing timeline

## Technologies Used

- Python
- Streamlit

## Installation

Clone the repository:

    git clone YOUR_REPOSITORY_URL

Install dependencies:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py
